# 今天吃什么 · 随机决定器

一个好看又好用的「今天吃什么」转盘：转一下，午饭晚饭就定了。清单可以自己加、自己删，关掉网页再打开数据还在。

👉 在线使用：**https://xiaor79.github.io/what-to-eat-today/**

## 功能

- **转盘决定**：点中心按钮或按 `空格` 开转，指针落在哪一格就吃哪一格；停下后中奖扇区会亮起来，结果卡片弹一下。
- **默认 5 样中国美食**：火锅、兰州拉面、小笼包、麻辣烫、黄焖鸡米饭。
- **自由增删**：输入框回车即添加（也有 `+ 饺子` 这类快捷推荐），每条右侧 `✕` 删除；删错、清空都能在提示里点「撤销」救回来。
- **数据本地留存**：清单、转动次数、历史结果都存在浏览器 `localStorage`（键名 `what-to-eat-today.v1`），刷新或重开浏览器都还在，不上传任何服务器。
- **顺手的细节**：自动给食物配 emoji、重名/空白输入给出提示、上限 30 样、重开页面显示「上次抽到」、可开关的转动音效、多标签页数据同步、窄屏自动改单列布局。
- **不做危险的事**：输入内容一律按纯文本渲染（不会把名字当 HTML 执行），超长名字截断到 24 字，存储数据损坏时自动回退到默认清单。

## 本地运行

整站只有一个 `index.html`，无依赖、无构建：

```bash
# 直接双击 index.html 即可；需要本地服务器时：
python -m http.server 8777
# 然后打开 http://127.0.0.1:8777/
```

## 测试

用 jsdom 加载真实的 `index.html` 并驱动完整交互流程（增删改、撤销、转动角度、持久化、脏数据兜底）：

```bash
npm install
npm test
```
